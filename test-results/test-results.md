#### 3. 職務内容・求める人物像のセクション終了判定が不正確

**問題点**:
- セクション終了条件が次の見出しキーワードまでとなっているが、その見出しキーワード自体が含まれてしまっている
- 例: 「報酬」「歓迎要件」などが職務内容や求める人物像に含まれている

**改善案**:
- 見出しキーワードを含む行自体は除外する
- 空行の連続をセクション終了条件に追加
- より多くの終了キーワードを定義

### 3. セクション抽出の改善

```typescript
function extractSection(content: string, startKeywords: string[], endKeywords: string[]): string | null {
  const lines = content.split('\n');
  let startIndex = -1;
  
  // 開始キーワードを探す
  for (let i = 0; i < lines.length; i++) {
    if (startKeywords.some(kw => lines[i].includes(kw))) {
      startIndex = i + 1;  // 見出し行の次の行から
      break;
    }
  }
  
  if (startIndex === -1) return null;
  
  // 終了条件: 終了キーワードを含む行、または空行が3行連続
  let emptyLineCount = 0;
  for (let i = startIndex; i < lines.length; i++) {
    if (endKeywords.some(kw => lines[i].includes(kw))) {
      return lines.slice(startIndex, i).join('\n').trim();
    }
    if (lines[i].trim() === '') {
      emptyLineCount++;
      if (emptyLineCount >= 3) {
        return lines.slice(startIndex, i - 2).join('\n').trim();
      }
    } else {
      emptyLineCount = 0;
    }
  }
  // ...
}
```
