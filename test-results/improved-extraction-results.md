## 追加改善が必要な項目

### 優先度1: 役職名抽出の修正（緊急）

**問題**: content内の「職種」セクションを探索する際、見出し行自体を抽出してしまっている

**修正案**:
```typescript
function extractJobTitle(title: string, content: string): string | null {
  // content内のセクション探索時、見出し行を除外
  const lines = content.split('\n');
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i].trim();
    if (line.includes('募集職種') || line.includes('職種') || line.includes('ポジション')) {
      // 見出し行の次の行を取得（見出し行自体は除外）
      if (i + 1 < lines.length) {
        const nextLine = lines[i + 1].trim();
        // 見出し行と同じパターン（「職種 / 募集ポジション」など）を除外
        if (nextLine.length > 0 && nextLine.length < 100 && 
            !nextLine.includes('職種') && !nextLine.includes('募集')) {
          return nextLine;
        }
        // 次の行も見出し行の場合は、さらに次の行を探索
        if (i + 2 < lines.length) {
          const nextNextLine = lines[i + 2].trim();
          if (nextNextLine.length > 0 && nextNextLine.length < 100) {
            return nextNextLine;
          }
        }
      }
    }
  }
  // ...
}
```
