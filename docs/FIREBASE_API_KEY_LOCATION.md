# Firebase APIキーの場所と更新方法

## 📍 Firebase APIキーの場所

### ステップ1: Firebase Consoleにアクセス

1. [Firebase Console](https://console.firebase.google.com/)にアクセス
2. ログイン（Googleアカウントで）

### ステップ2: プロジェクトを選択

1. プロジェクト一覧から **`job-seiri`** を選択

### ステップ3: プロジェクト設定を開く

1. 画面左上の **歯車アイコン（⚙️）** をクリック
2. **「プロジェクトの設定」** をクリック

### ステップ4: APIキーを確認

1. **「全般」タブ** が開いていることを確認（デフォルトで開いています）
2. ページを下にスクロール
3. **「APIキー」** セクションを探す
4. 現在のAPIキーが表示されます

## 🔄 APIキーの更新方法

### 方法1: 既存のAPIキーを制限する（推奨）

1. **「APIキー」セクション** で、漏洩したAPIキー `AIzaSyDg3-q0Hn-GBitx3NscOp6hQ9Fw3LWfRzw` を探す
2. APIキーの右側にある **「編集」** または **「削除」** をクリック
3. **「削除」** を選択して古いAPIキーを削除
4. または、**「アプリの制限」** を設定して特定のアプリからのみ使用可能にする

### 方法2: 新しいAPIキーを作成する

1. **「APIキー」セクション** の右上にある **「APIキーを作成」** をクリック
2. APIキー名を入力（例：`Web App - Production`）
3. **「作成」** をクリック
4. 新しいAPIキーが表示されます（**この時点でコピーしてください**）
5. **「閉じる」** をクリック

## 📋 新しいAPIキーをNetlifyに設定

1. [Netlifyダッシュボード](https://app.netlify.com/)にアクセス
2. サイト `kyujin-bookmark` を選択
3. **サイト設定 → Environment variables** を開く
4. `NEXT_PUBLIC_FIREBASE_API_KEY` を探す
5. **「Edit」** をクリック
6. 新しいAPIキーを貼り付け
7. **「Save」** をクリック
8. **新しいデプロイを実行**（重要！）

### APIキーセクションの見た目

- **「APIキー」** という見出し
- その下にAPIキーの一覧が表示される
- 各APIキーの右側に「編集」「削除」ボタンがある
- 右上に「APIキーを作成」ボタンがある

## ⚠️ 注意事項

1. **APIキーをコピーする**: 新しいAPIキーを作成したら、すぐにコピーしてください。後から確認するのは難しい場合があります。

2. **古いAPIキーを削除**: 漏洩したAPIキーは必ず削除または無効化してください。

3. **Netlify環境変数を更新**: 新しいAPIキーをNetlify環境変数に設定した後、**必ず新しいデプロイを実行**してください。

4. **動作確認**: デプロイ後、Webアプリでログインできることを確認してください。
