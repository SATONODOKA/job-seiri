# LLMプロンプト設計ドキュメント

## サービスの全体像

### データフロー
```
[1] Chrome拡張機能 (popup.js)
    ↓ ページ情報取得 (getPageInfo)
    ↓ POST /api/jobs/capture
[2] API Route (app/api/jobs/capture/route.ts)
    ↓ LLM抽出 (extractWithGemini)
    ↓ Firestore保存
[3] UI表示 (JobCard, JobList, JobFilters)
    ↓ フィルター・ソート機能
```

### 再抽出機能
- `/api/jobs/extract-on-client`: クライアント側から再抽出（companyName/jobTitle/salaryBandがない場合）
- `/api/jobs/re-extract`: 既存データの再抽出

## 抽出情報の優先度

### 最重要（UIで必須表示・フィルター対象）
1. **companyName（会社名）**
   - JobCardのタイトルに表示: `{companyName}：{jobTitle}`
   - ソート対象
   - 必須: 可能な限り抽出

2. **jobTitle（職種名）**
   - JobCardのタイトルに表示: `{companyName}：{jobTitle}`
   - ソート対象
   - 必須: 可能な限り抽出

3. **salaryBand（年収帯）**
   - JobCardにバッジ表示: "〜500万円", "500-700万円", "700-900万円", "900万円以上"
   - フィルター対象
   - 必須: salaryMin/salaryMaxから自動計算可能

### 重要（UIで表示・フィルター対象）
4. **salaryMin, salaryMax（年収）**
   - JobCardにバッジ表示（salaryBandがない場合）
   - ソート対象（salaryMin）
   - 必須: 可能な限り抽出

5. **jobType（職種カテゴリ）**
   - JobCardにバッジ表示（緑色）
   - フィルター対象
   - 例: "エンジニア", "デザイナー", "営業", "マーケティング", "PM", "データサイエンティスト"

6. **industry（業種）**
   - JobCardにバッジ表示（紫色）
   - フィルター対象
   - 例: "IT", "金融", "製造業", "コンサルティング", "広告・マーケティング"

### 補助（詳細表示）
7. **locationText（勤務地）**
8. **remoteType（リモートワーク種別）**
9. **employmentType（雇用形態）**
10. **jobDescription（仕事内容）**
11. **requiredPerson（求める人物像）**
12. **requiredYears（必要経験年数）**
13. **seniorityLevel（シニアリティレベル）**

## 抽出のポイント

### URLからの推測
- ドメイン名から会社名を推測可能
- 例: `https://careers.toyota.co.jp/...` → "トヨタ自動車株式会社"
- 例: `https://www.rakuten.careers/...` → "楽天グループ株式会社"

### タイトルからの推測
- タイトルに会社名が含まれる場合が多い
- 例: "トヨタ自動車株式会社 求人" → companyName: "トヨタ自動車株式会社"
- 例: "プラットフォーム戦略統括部　顧客戦略部　コーポレート：UXデザイナー（CSD）" → jobTitle: "UXデザイナー（CSD）"

### よくある表記パターン

#### 会社名
- "株式会社○○", "○○株式会社", "合同会社○○", "有限会社○○"
- URLのドメイン名から推測
- タイトルに含まれる

#### 職種名
- 「募集職種」「職種」「ポジション」「採用職種」セクション
- タイトルに含まれる
- 見出し行の直後

#### 年収
- "500万円", "500万", "500万円以上", "500万円〜800万円"
- "月給30万円" → 年収360万円
- "時給2000円" → 年収に変換（月160時間×12ヶ月）
- 全角数字・半角数字両方に対応

#### 職種カテゴリ（jobType）
- エンジニア系: "エンジニア", "プログラマー", "SE", "インフラエンジニア", "フロントエンドエンジニア", "バックエンドエンジニア"
- デザイナー系: "デザイナー", "UIデザイナー", "UXデザイナー", "グラフィックデザイナー"
- 営業系: "営業", "セールス", "営業企画"
- マーケティング系: "マーケティング", "マーケター", "マーケティング企画"
- PM系: "プロジェクトマネージャー", "PM", "プロダクトマネージャー"

#### 業種（industry）
- IT系: "IT", "ソフトウェア", "インターネット", "SaaS"
- 金融系: "金融", "銀行", "証券", "保険"
- 製造業: "製造業", "自動車", "電機"
- コンサルティング: "コンサルティング", "経営コンサル"
- 広告・マーケティング: "広告", "マーケティング", "PR"
